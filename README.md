## Selected app work

### Screen Mirror: TV Media Cast

An Android app for connecting a phone to a TV, screen mirroring, and sharing local media. My contributions include improving receiver discovery across Google Cast, DLNA, and AirPlay, removing duplicate device entries, handling connection failures, and making local media playback more predictable.

I’ve also fixed an offline startup crash, improved navigation after ad dismissal, added regression tests and diagnostic logging, and worked on onboarding and premium screens.

**Stack:** Kotlin, Jetpack Compose, MVVM, Coroutines, Flow/StateFlow, Google Cast SDK, DLNA/UPnP, Media3/ExoPlayer, Ktor, WebSockets, Firebase, and Google Play Billing.

[View on Google Play](https://play.google.com/store/apps/details?id=casttv.screenmirroring.chromecast.player)

### AI Voice Changer & Text-to-Speech

I contributed to recording, voice effects, playback, and AI voice features. I implemented an API-integrated Text-to-Speech module supporting 18+ languages and worked with asynchronous voice-generation flows.

**Stack:** Kotlin, MVVM, Hilt, Coroutines, Flow, REST APIs, Android audio APIs, and Material Design.

[View on Google Play](https://play.google.com/store/apps/details?id=ai.voice.changer.app) · [Public code sample](https://github.com/Muhammad-muaz-dev/AIVoiceChangerEffects)

### Phone Cleaner

I worked on storage analysis, duplicate-file detection, image compression, app management, and file browsing. This project helped me build practical experience with Android storage and maintainable app architecture.

**Stack:** Kotlin, MVVM, Hilt, and Android Jetpack.
